# Chapter 2 - C言語の基礎を総復習しよう①

## ■ Practice / Experiment（重要）

- ハンズオン1

```c
#include <stdio.h> // <stdio.h>をインクルード、これは標準的な入出力を行う機能を備えるヘッダー

int main(void) // main関数の定義
{
printf("C言語の総復習 \n"); // printf() で文字列を出力、\n は出力内容を開業するコード
return 0; // 0を返す
}
```

## ■ Learning（学び）

- main関数はC言語やC++で書かれたプログラムで最初に実行される関数
    - main関数の処理が終わるとプログラムも終了する
    - 終了時にa main関数の戻り値が、そのプログラムが動いていた処理系（実行環境）に返される

```cpp
int main(void) // C++だと int main() とすることが一般的
{ // main関数の始まりの波括弧
	処理 // 必要な処理を記述する
	return 0; // 通常、return 0 としてゼロを返す
}  // main関数の終わりの波括弧
```

- return は関数から値を返す**キーワード**
    - **キーワード**とはプログラムを記述する際に特定の機能や命令を表すために予約されている単語
- 関数の処理のまとまりを `｛｝`でくくる
    - `｛｝`の間を、その関数のブロックという
- printf() のように () の付いた命令はC言語やC++に備わる関数
    - return のように () を付けない命令はキーワード
 - `%d` は、出力するデータの表示形式を指定する変換指定子
    - よく使われる変換指定子
        - `%d`：整数
        - `%f`：少数
        - `%c`：文字
        - `%s`：文字列
- `scanf("%d", &life);`
    - 1つ目の引数を`%d`として、整数の入力を受け付けている
    - 入力した値は2つ目の引数に代入される
    - `&変数名`とすると、その変数がコンピュータのメモリ上のどこにあるか（変数のアドレス）を知ることができる
    - `scanf()`の2つ目の引数にはアドレスを渡す決まりなので、`&`をつける
    - `scanf()`は使い方を誤ると処理に悪影響を及ぼす可能性がある
    - Microsoftは、`scanf_s()`という安全な関数の使用を推奨している
- ゲームにも入力、演算、出力という処理の流れがある
    - 入力（キーボードからの入力を**標準入力**という）
        - コントローラやタッチパネルでの操作
    - 演算
        - 入力値を元にプログラムでキャラクターを動かす計算
        - ゲームルールの判定
        - 画面遷移
    - 出力（液晶画面などへの出力を**標準出力**という）
        - 計算や判定した結果を液晶表示部などに映像として出力
        - スピーカーから音を出力
- 変数を使うには**型（データ型）**と**変数名**を宣言する
    - C言語で2文字以上の半角文字を扱ったり、全角文字を扱うには、文字列を代入する配列を使用する
- `int`：整数を扱う
- `float`：小数を扱う
- `char`(チャーあるいはキャラ)：半角1文字を扱う
    - 半角1文字を扱うときは、それをシングルクォート`’’`でくくる
- 変数や関数に付ける名前を**識別子**といい、識別子を決めるルールは以下の通り
    - 半角a~z、A~Z、0~9、及び、_（アンダースコア）を使用できる
    - 数字から始めてはいけない
        - 123a、9x などはNG
    - アルファベットの大文字と小文字は区別される
        - Apple、apple は別の変数になる
    - キーワード（予約語）は変数名として使用できない
    - printf、scanf などの標準ライブラリで定義された関数名を変数名にすべきでない
- 重要なデータを扱う変数は、何を扱うのか分かりやすい変数名にするべき
    - その場で使い捨てる変数はアルファベット1文字などの簡素なものでOK
- 整数を扱う型

| 型 | サイズ（バイト） | ビット数 | 扱える値の範囲 | 補足 |
| --- | --- | --- | --- | --- |
| char | 1 | 8 bit | -128 ~ 127 or 0 ~ 255  | 半角1文字を代入でき、数では -128 ~ 127 か 0 ~ 255 の値を扱える  |
| short | 2 | 16 bit | -32768 ~ 32767 |  |
| int | 2 or 4 | 16 or 32 bit | -32768 ~ 32767 or -2147483648 ~ 2147483647 | int と long は開発環境によってサイズが異なる。Visual Studioでは、int, long ともに4byte で、long long と宣言すると8byteになる |
| long | 4 or 8 | 32 or 64 bit | 約 -21 億 ~ 21億 or 約 900 京 ~ 900 京 |  |
- 上記の表にあるサイズは、その型の変数を1つ用意するのに必要なメモリのバイト数
    - 変数で扱える値の範囲を超えると、その変数はオーバーフローを起こす
- 宣言時に`unsigned`という型指定子を付けると、0以上の正の整数を扱う変数を作ることができる
    - unsigned char a：変数aで扱える範囲は 0~255 になる
    - unsigned int x：変数xで扱える範囲は 0~4294967295 になる
        - これはint型が4バイトの場合
        - 2バイトの環境だと 0~65535 になる
- 小数を扱う方

| 型 | サイズ（バイト） | ビット数 | 扱える値の範囲 | 補足 |
| --- | --- | --- | --- | --- |
| float | 4 | 32 bit | 約 -3.4e+38 ~ 約 3.4e+38 | ※小数は正負によって範囲が変わり、ここに記したのは目安の値 ※ 1e-2 は 1×10-2乗=0.01、1e+2 は 1×10 2乗=100.0 になる |
| double | 8 | 64 bit | 約 -1.7e+308 ~ 約 1.7e+308 |  |
- `float` よりも `double` の方が高い精度を持つため、精度が求められる計算では `double` を使用することが推奨される
    - 計算速度やメモリの節約を優先したり、精度がそこまで必要でない時に `float` を使うこともある
- `sizeof`で型や変数のサイズ（バイト数）を調べることができる
