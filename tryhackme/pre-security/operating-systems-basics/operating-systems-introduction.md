## メモ **/ Notes**

#### Operating System (OS)

- コンピュータ全体を管理する中核ソフトウェア
    - ユーザー、アプリケーション、ハードウェアの仲介役として動作する
    - CPU、メモリ、ストレージなどのリソースを効率的に管理する
    - 例：Windows、Linux、macOS

---

#### Kernel Space（カーネル空間）

- OSの中核であるカーネルが動作する特権領域
    - CPUやメモリなどのハードウェアへ直接アクセスできる
    - システム全体の安定性と安全性を維持する役割を持つ
    - 不正なアクセスや障害からシステムを保護する

---

#### User Space（ユーザー空間）

- 一般的なアプリケーションが動作する領域
    - ブラウザやテキストエディタなどが実行される
    - ハードウェアへ直接アクセスすることはできない
    - 必要な処理はシステムコールを通じてカーネルへ依頼する

---

#### System Call（システムコール）

- ユーザー空間からカーネル空間へ機能を要求する仕組み
    - ファイル操作やネットワーク通信などを実行する際に利用される
    - OSが安全にハードウェアを管理するための重要なインターフェース
    - 例：ファイルの読み書き、音声再生、Wi-Fi接続

---

### Operating System Duties（OSの主な役割）

#### Process Management（プロセス管理）

- 実行中のプログラムを管理する機能
    - プロセスの作成、実行、終了を制御する
    - CPU時間を各プロセスへ適切に割り当てる
    - 複数アプリを同時に利用できるマルチタスクを実現する

**例**

- ブラウザで調べ物をしながら音楽を再生し、チャットアプリを利用できる

---

#### Memory Management（メモリ管理）

- RAM（メモリ）を効率的に管理する機能
    - 各プロセスへ必要なメモリを割り当てる
    - プロセス同士が互いのメモリ領域へ干渉しないよう保護する
    - メモリ不足時は仮想メモリを利用してシステムの安定性を維持する

**例**

- 複数のアプリを起動しても、それぞれ独立したメモリ領域で動作する

---

#### File System Management（ファイルシステム管理）

- ファイルやフォルダを整理・管理する機能
    - ファイル名や保存場所（パス）を管理する
    - アクセス権限やメタデータを保持する
    - データを効率的に保存・検索できるようにする

**例**

- フォルダの作成、ファイル保存、読み取り専用設定

---

#### User Management（ユーザー管理）

- ユーザーアカウントと権限を管理する機能
    - ログイン認証を行う
    - ユーザーごとのアクセス権限を制御する
    - 個人データやシステムリソースを保護する

**例**

- パスワード認証によるログイン
- 他ユーザーから自分のファイルを保護する

---

#### Device Management（デバイス管理）

- ハードウェアを統一的に管理する機能
    - デバイスドライバを利用して機器を制御する
    - アプリケーションへ共通インターフェースを提供する
    - ハードウェアの違いを意識せず利用できるようにする

**例**

- マウスやプリンターを接続すると自動的に利用可能になる

---

#### Hardware Abstraction Layer (HAL)

- ハードウェアの違いを隠蔽する仕組み
    - アプリケーションは機器ごとの差異を意識せず利用できる
    - OSがハードウェアごとの制御を吸収する
    - ソフトウェアの互換性と開発効率を向上させる

**例**

- メーカーが異なるプリンターでも同じ操作で印刷できる

---

#### ポイント

- **Kernel Space = OSの管理者エリア**
- **User Space = アプリが動くエリア**
- **System Call = アプリからOSへのお願い**
- **Process = 実行中のプログラム**
- **Memory Management = RAMの割り当て管理**
- **File System = ファイル整理の仕組み**
- **Device Driver = OSとハードウェアをつなぐソフトウェア**
