## 概要 **/ Overview**

デジタルフォレンジックと関連するプロセスについて学び、実践的な例を用いて実際に試してみる

## 実施内容 **/ Practical Work**

- 仮想環境でハンズオンをしながら、設問に答える。
- `pdfinfo` を使用して、添付PDFファイル **ransom-letter.pdf** の作成者（Author）を調べてください。
    - pdfinfo ransom-letter.pdf
    - Author: が確認できた

- `exiftool` または類似ツールを使用して、誘拐犯が文書に添付した画像が撮影された場所を調べてください。その通り（Street）の名前は何ですか？
    - exiftool letter-image.jpg
    - GPS Position: 51 deg 30' 51.90" N, 0 deg 5' 38.73" W 
    - 51°30'51.9"N 0°05'38.7"W で検索（deg → ° で変換）し、Street名が確認できた
        
- この写真の撮影に使用されたカメラのモデル名は何ですか？
    - exiftool letter-image.jpg
    - Camera Model Name: で確認できた


## 気づき・考察 **/ Key Insights & Analysis**

- フォレンジックでは、単に証拠を集めるだけでなく、元データを変更しないこと（データ完全性） が非常に重要だと学んだ。証拠が改ざんされたと疑われると、分析結果の信頼性も失われてしまう。
- 普段何気なく使っているPCやスマートフォンでも、操作の多くが痕跡として残っている と気づいた。防御側では証拠になる一方で、利用者側ではプライバシー意識も必要だと思った。

## メモ **/ Notes**

- Write Blocker
    - 証拠データへの書き込みを防ぎ、データ完全性を維持する
- Chain of Custody
    - 証拠の収集者、保管場所、アクセス履歴などを管理する文書
- Disk Image
    - HDDやSSDの内容をビット単位でコピーしたもの（不揮発性データ）
- Memory Image
    - RAMの内容をコピーしたもの（揮発性データ）
- Volatile Data
    - 再起動やシャットダウンで消えるデータ（プロセス、通信情報など）
- Metadata
    - ファイルに含まれる付加情報（作成者、日時、使用ソフトなど）
- EXIF
    - 画像内に保存される情報（GPS、カメラ機種、撮影日時など）
