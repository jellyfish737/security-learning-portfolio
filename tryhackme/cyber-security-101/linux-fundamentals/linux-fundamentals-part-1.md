## 気づき・考察 **/ Key Insights & Analysis**

- `grep`による文字列検索は、ログ解析やIOC（IP・ドメイン・フラグ・コマンド痕跡）の抽出に直結する。大量データから「意味のある1行」を抜く基本技術。
- ファイルの探索（`ls`, `find`）は、侵害調査で「どこに不審なファイルがあるか」を素早く絞り込む基本動作になる。特に拡張子や名前ベース検索は初動調査で重要。

## メモ **/ Notes**

- Linux
    - オープンソースのOS群の総称
    - 用途に応じたさまざまなディストリビューション（Ubuntu、Debianなど）が存在する
- `echo`
    - 指定したテキストをそのまま出力する
    - ファイルへの書き込みや動作確認でよく利用される
- `whoami`
    - 現在ログインしているユーザー名を確認する
    - 権限確認やユーザー切り替え後の検証に便利
- `ls`
    - ファイルやディレクトリの一覧を表示する
    - 対象ディレクトリの構成を素早く把握できる
- `cd`
    - ディレクトリを移動する
    - Linux操作の基本となるコマンド
- `pwd`
    - 現在の作業ディレクトリの絶対パスを表示する
    - 今どこで作業しているか確認できる
- `cat`
    - ファイルの内容を表示する
    - 設定ファイルやログの内容確認に利用する
- `find`
    - ファイルやディレクトリを検索する
    - 保存場所が分からないファイルの特定に役立つ
    
    例:
    
    ```
    find -name passwords.txt
    ```
    
- ワイルドカード ()
    - ファイル名の一部が不明な場合に利用する
    - 条件に一致する複数のファイルを検索できる
    
    例:
    
    ```
    find -name "*.txt"
    ```
    
- `grep`
    - ファイル内の特定の文字列を検索する
    - ログ解析や設定ファイル調査で頻繁に利用される
    
    例:
    
    ```
    grep "81.143.211.90" access.log
    ```
    
- `grep -R`
    - ディレクトリ配下を再帰的に検索する
    - 複数ファイルにまたがる設定や情報の調査に便利
    
    例:
    
    ```
    grep -R "PRETTY_NAME" /etc/
    ```
    
- `wc -l`
    - ファイル内の行数を数える
    - ログ件数やデータ量の確認に利用する
    
    例:
    
    ```
    wc -l access.log
    ```
    
- `&`
    - コマンドをバックグラウンドで実行する
    - 長時間かかる処理を実行しながら他の作業を続けられる
    
    例:
    
    ```
    command &
    ```
    
- `&&`
    - 複数のコマンドを順番に実行する
    - 前のコマンドが成功した場合のみ次を実行する
    
    例:
    
    ```
    command1 && command2
    ```
    
- `>`
    - コマンドの出力をファイルへ書き込む（上書き）
    - 既存ファイルがある場合は内容が置き換わる
    
    例:
    
    ```
    echo hey > welcome
    ```
    
- `>>`
    - コマンドの出力をファイル末尾へ追記する
    - 既存データを残したまま内容を追加できる
    
    例:
    
    ```
    echo hello >> welcome
    ```
    

- `wc -l "FILE NAME"`
