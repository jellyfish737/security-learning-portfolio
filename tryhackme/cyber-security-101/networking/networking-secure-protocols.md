## 概要 **/ Overview**

LS、SSH、VPNがネットワークトラフィックをどのように保護するかについて学ぶ

## 実施内容 **/ Practical Work**

- 仮想環境での実践的なチャレンジに挑戦する。
- パケットの1つにログイン認証情報が含まれています。ユーザーが送信したパスワードは何ですか？
    - No366 HTTP2 info:DATA[15] のパケットの詳細を確認
    - HTML Form URL Encoded内の "pass" を確認し正解！ 


## 気づき・考察 **/ Key Insights & Analysis**

- HTTPS や SMTPS のように TLS が使われていても、今回のように `ssl-key.log` や復号鍵を取得できれば通信内容を復元できる場合がある。
- SSH や VPN は安全な通信手段として使われる一方で、攻撃者も C2 通信（遠隔操作）やデータ持ち出しに悪用する可能性がある。そのため、「暗号化通信＝正規通信」と決めつけない視点が必要。
- VPN を利用すると接続元 IP を隠せるため、攻撃者の追跡が難しくなることがある。

## メモ **/ Notes**

- **TLS (Transport Layer Security)**
    - 通信内容を暗号化し、盗聴・改ざん・なりすましを防ぐ仕組み
- **HTTPS**
    - HTTPにTLSを追加した安全なWeb通信
    - Webサイトとの通信内容を第三者から保護できる
- **SSH (Secure Shell)**
    - サーバーへ安全にリモートログインするためのプロトコル
    - Telnetと異なり通信内容が暗号化される
- **TLS証明書**
    - サーバーの正当性を証明する電子証明書
    - 利用者は接続先が本物のサーバーか確認できる
- **認証局（CA）**
    - TLS証明書の正当性を保証する第三者機関
    - ブラウザはCAを信頼して証明書を検証する
- **CSR（Certificate Signing Request）**
    - サーバー管理者が認証局へ証明書発行を依頼するための申請情報
- **Let's Encrypt**
    - 無料でTLS証明書を発行できる認証局
    - 現在多くのWebサイトで利用されている
- **自己署名証明書（Self-Signed Certificate）**
    - 自分で作成した証明書
    - 第三者による保証がないため、本番環境では信頼されない

### TLSによる安全な通信

- **HTTPS通信の流れ**
    - TCP接続を確立
    - TLSセッションを確立
    - HTTP通信を開始
- **暗号化通信**
    - TLSによって通信内容が暗号化される
    - 通信経路上で内容を見られても解読が困難
- **Secure版プロトコル**
    - HTTP → HTTPS
    - SMTP → SMTPS
    - POP3 → POP3S
    - IMAP → IMAPS
    - TLSを利用することで安全な通信が可能になる

---

### SSH

- **安全なリモート管理**
    - サーバーを遠隔操作する際の標準的な方法
    - 管理者が最も頻繁に利用するプロトコルの一つ
- **公開鍵認証**
    - パスワードを使わず安全にログインできる認証方式
    - パスワード認証より高いセキュリティを実現できる
- **SSHトンネリング**
    - SSHの暗号化通信を利用して他の通信を安全に転送する仕組み
- **X11フォワーディング**
    - SSH経由でリモート環境のGUIアプリを利用できる機能
- **SSHのデフォルトポート**
    - TCP 22番ポートを使用する
- **Telnetとの違い**
    - Telnetは平文通信
    - SSHは暗号化通信

---

### SFTP / FTPS

- **SFTP (SSH File Transfer Protocol)**
    - SSHを利用した安全なファイル転送プロトコル
    - SSHと同じ22番ポートを使用する
- **SFTPの特徴**
    - ファイルのアップロード・ダウンロードを安全に実行できる
    - OpenSSH環境で簡単に利用できる
- **FTPS (FTP Secure)**
    - FTPにTLSを追加した安全なファイル転送方式
    - TLS証明書の管理が必要
- **SFTPとFTPSの違い**
    - SFTPはSSHベース
    - FTPSはFTP+TLSベース
    - 名前は似ているが別のプロトコル

---

### VPN（Virtual Private Network）

- **VPN**
    - インターネット上に安全な専用通信経路（トンネル）を作る技術
- **VPNトンネル**
    - クライアントとVPNサーバー間の通信を暗号化する
    - 第三者による盗聴リスクを低減できる
- **リモートアクセス**
    - 社外や自宅から社内ネットワークへ安全に接続できる
- **IPアドレスの隠蔽**
    - VPN利用時は接続先からVPNサーバーのIPアドレスが見える
    - 実際の利用者のIPアドレスは直接公開されない
- **拠点間VPN**
    - 本社と支社など複数拠点を安全に接続できる
- **リモートユーザーVPN**
    - 個人ユーザーが社内ネットワークへ安全にアクセスできる
- **DNSリーク**
    - VPN利用中でもDNS通信がVPN外へ送信される問題
    - VPN利用時はDNSリーク対策も重要
- **VPN利用時の注意**
    - 国によってはVPN利用に規制や制限が存在する
    - 利用前に現地法令を確認する
