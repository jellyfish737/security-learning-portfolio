## 概要 **/ Overview**

サイバーセキュリティの専門家にとっての「スイスアーミーナイフ」とも言える「CyberChef」について学ぶ

## 実施内容 **/ Practical Work**

- 実際にCyberChefを操作して設問に答える。
- 10進数 78 のバイナリ値は何ですか？
    - “From decimal”と “To Binary”のレシピを使う→正解！
      
- 次のURLをURLエンコードするとどうなりますか？`https://tryhackme.com/r/careers`
    - “URL Encode”レシピで Encode all special chars にチェックを入れる→正解！
      
- Unix タイムスタンプ `1725151258` に対応する日時文字列は何ですか？
    - From UNIX Timestamp を使う→正解！
      
- `<+oue+DGm>Ap%u7` を Base85 デコードした結果の文字列は何ですか？
    - From base85 →正解！

## 気づき・考察 **/ Key Insights & Analysis**

- マルウェアは文字列をそのまま保存せず、Base64 や URL エンコードで難読化していることがある。一見意味不明な文字列でも、まずは CyberChef でデコードを試す価値があると感じた。
- フォレンジック調査ではログやメモリダンプから大量のデータを確認することになる。IPアドレスやURL、メールアドレスを自動抽出できる機能は調査時間の短縮に役立つと感じた。
- マルウェア解析やフォレンジックでは「試行錯誤」が重要だと感じた。一度で正解にたどり着けなくても、別のデコード方法や変換方法を順番に試す姿勢が必要だと学んだ。

## メモ **/ Notes**

- CyberChef
    - ブラウザ上で利用できるデータ変換・解析ツール
    - 「サイバーセキュリティのスイスアーミーナイフ」と呼ばれる
    - エンコード、デコード、暗号化、復号、データ抽出などをGUIで実行できる
- Recipe（レシピ）
    - CyberChef の中核機能
    - 複数の処理を順番に組み合わせて実行できる
    - 処理の流れを保存・再利用できる
- Operations
    - 利用可能な処理の一覧
    - 検索機能で目的の処理を素早く探せる
    - Base64、ROT13、URL Encode など多数の操作を利用可能
- Input / Output
    - Input に解析対象のデータを入力する
    - Output に処理結果が表示される
    - ファイルの読み込みや結果の保存にも対応している
- BAKE!
    - 作成したレシピを実行するボタン
    - Auto Bake を有効にすると入力変更時に自動実行される
- CyberChef の基本的な使い方
    - 「何をしたいか」を明確にする
    - データを入力する
    - 適切な Operation を選択する
    - 出力結果を確認する
    - 期待した結果でなければ別の方法を試す
- Extract IP Addresses
    - 入力データから IPv4 / IPv6 アドレスを抽出する
    - ログ解析やインシデント対応で有用
- Extract Email Addresses
    - 入力データからメールアドレスを抽出する
    - OSINT やログ調査で活用できる
- Extract URLs
    - 入力データから URL を抽出する
    - 不審なリンクやアクセス先の調査に役立つ
- Base64
    - バイナリデータを文字列として表現するエンコード方式
    - メール、Web通信、CTFなどで頻繁に利用される
    - 暗号化ではなくエンコードである点に注意
- From Base64
    - Base64文字列を元のデータへ復元する
    - 不審な文字列の解析でよく使用する
- URL Encode / Decode
    - URLで使用できない文字を変換・復元する
    - `%3A` → `:`
    - `%2F` → `/`
    - Webアプリケーション解析で頻出
- ROT13
    - アルファベットを13文字ずらすシーザー暗号
    - CTFや簡易的な難読化で見かけることがある
- Hex（16進数）
    - データを16進数形式で表現する
    - バイナリ解析やフォレンジックでよく利用される
- UNIX Timestamp
    - 1970年1月1日からの経過秒数を表す時刻形式
    - ログ分析で頻繁に登場する
    - CyberChef で日時と相互変換できる
- Base85 / Base58 / Base62
    - Base64以外のエンコード方式
    - 文字数削減や可読性向上を目的に利用される
    - CTFやマルウェア解析で遭遇することがある
- CyberChef が活躍する場面
    - CTF
    - フォレンジック調査
    - ログ解析
    - OSINT
    - マルウェア解析
    - Webアプリケーション診断
- 学んだこと
    - CyberChef は複雑なデータ変換をGUIで実行できる
    - エンコードやタイムスタンプ変換を素早く試行錯誤できる
    - 「入力 → レシピ作成 → 実行 → 結果確認」の流れが重要
    - サイバーセキュリティ学習で最初に覚えておくべき便利ツールの一つである
